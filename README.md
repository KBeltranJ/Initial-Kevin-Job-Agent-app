# Kevin Job Agent — Version 1

This is an installable Progressive Web App (PWA) starter.

## What works now
- Mobile-first dashboard
- Fit scores
- Resume A/B/C recommendations
- Save / Skip / Applied tracking
- Salary and location preferences
- Local storage on the device
- Offline support
- Android install after hosting

The current jobs are demo entries so you can test the interface.

## Host with GitHub Pages
1. Create a GitHub repository named `kevin-job-agent`.
2. Upload every file and folder from this package to the repository.
3. Open repository Settings > Pages.
4. Set Source to `Deploy from a branch`.
5. Select branch `main` and folder `/(root)`.
6. Save.
7. Open the HTTPS URL GitHub gives you on Android.
8. In Chrome, tap the three-dot menu > Add to Home screen / Install app.

## Security
Never put an OpenAI API key directly in `app.js` or any browser file.
Live job search should be added through a secure backend.
